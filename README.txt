AUTOSELECT — Лабораторная работа 4.1

1. Распакуйте ZIP-архив полностью.
2. Откройте файл Car.html в браузере Chrome, Edge или Firefox.
3. Нажимайте «+ Выбрать» на карточках — корзина и сумма обновляются автоматически.
4. Попробуйте поиск, сортировку, удаление из корзины, «Сбросить выбор» и «Посмотреть чек».
5. Кнопка печати позволяет распечатать чек (или сохранить его как PDF).

Файлы проекта:
Car.html — HTML-разметка
style.css — оформление и адаптивность
car.js — данные, выбор, расчёт, поиск, сортировка, чек
Отчёт_Лаб4.1.docx — объяснения и результаты
screenshots/ — иллюстрации работы страницы

Важно: фотографии загружаются по внешним ссылкам с Wikimedia Commons при наличии интернета. Если фотография не загрузилась, показывается аккуратная заглушка. Для реальной публикации проекта следует проверить лицензии и авторов конкретных изображений.
Цены взяты из лабораторного задания и являются учебными. Рейтинги вымышлены для демонстрации интерфейса.
